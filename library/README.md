# Skill Library Maintenance

`library/` owns reusable skill-library maintenance, not project production work. [Skill authoring](skills/skill-authoring/SKILL.md) and its [template](templates/SKILL_TEMPLATE.md) live here so no production engine privately owns the definition of a reusable skill.

This library preserves the existing authoring procedure. Optional Skill Behavior Verification remains a conditional capability candidate, **not** an implemented universal gate or permission to add tests without an actual task requirement.
